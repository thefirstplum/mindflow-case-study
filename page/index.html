다음 세션은 이번 대화를 모르니까 커밋 본문과 주석이 인수인계 역할을 한다. 본문은 규약, 증상, 수정, 검증 순으로 썼다.

fix(gcal): 종일 일정이 만들어지지 않던 문제 — end.date 미포함 규약
규약
Google Calendar의 종일 일정 end.date는 ‘미포함(exclusive)’이다. 7월 29일 하루짜리 = start 2026-07-29 / end 2026-07-30.
증상
입력값을 그대로 보내 start == end가 되어 길이 0짜리 일정이 만들어졌다. 표시 조건이 start <= day < end라 어떤 날에도 안 걸려 영원히 안 보였다.
수정
_gcalShiftDateStr / _gcalShiftDays 헬퍼 추가. 저장 시 종일이면 종료일 +1일, 편집으로 열 때 −1일.
검증
순수 함수 재현. 하루짜리가 해당 날에만 표시 / 3일짜리가 정확히 3일 / 편집 왕복 시 원래 입력값 복원 / 월말 경계(7/31 → 8/1) / 종료일 공백 보정.

주석에는 하면 안 되는 걸 주로 적었다. 아래 두 개는 둘 다 한 번 겪은 버그에서 나왔다.
