# 작업 방식

버그 하나를 처리하는 순서는 대략 이렇게 고정했다.

1. 증상 제보 ("가끔 동기화 실패가 떠요")
2. 원인 경로를 먼저 찾게 함
3. 대안 비교 후 선택
4. 구현
5. 검증
6. 커밋 본문과 주석에 이유를 남김

구현은 AI가 빠르고, 내가 붙잡고 있던 건 2, 5, 6번이다.

## 원인 경로

"고쳐줘" 대신 "이 표시가 켜지는 경로를 전부 찾아서 각 분기 조건을 나열해줘"라고 요청했다. 이렇게 잡은 것들:

- 동기화 실패 표시: 원인 셋이 겹쳐 있었다 (발췌 6)
- 지운 메모 부활: 로컬/원격 두 쪽만 비교해서는 "방금 만든 메모"와 "남이 지운 메모"가 구분이 안 됐다 (발췌 2)
- 검색 0건: 한글 제목 일부가 NFD로 저장돼 있었다 (발췌 5)
- 커서 소실: 화면을 다시 그리는 경로가 셋인데 서로 입력 중인지 몰랐다 (발췌 7)

## 검증

Google Calendar 종일 일정 버그는 `end.date`가 미포함이라는 규약을 몰라서 생겼다. 7월 29일 하루짜리면 end가 07-30이어야 한다.
날짜 함수를 떼어내 하루짜리/3일짜리 표시, 편집 왕복, 월말(7/31에서 8/1), 종료일 공백을 node로 돌려 확인했다.

한글 NFD 건은 데이터를 하나씩 셌다. 메모 49개 중 NFD 제목 19개, 태그와 본문은 전부 NFC.
수정 후 백업과 비교해 본문 49개 그대로, 제목 19개만 변경. 앱의 검색 함수로 '까르보나라' 0건에서 2건, '부타노가쿠니' 0건에서 5건.

빌드가 없으니 작업 끝에 이 정도는 돌렸다.

```bash
for f in js/*.js; do node --check "$f"; done
for f in js/*.js; do grep -oE "^(function|const|let) [A-Za-z0-9_]+" "$f"; done | sort | uniq -d
node -e "h=require('fs').readFileSync('index.html','utf8');
  console.log((h.match(/<div/g)||[]).length, (h.match(/<\/div>/g)||[]).length)"
```
