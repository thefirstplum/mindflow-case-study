# CLAUDE.md 규칙

세션이 바뀌면 AI는 이전 대화를 모르니 규칙은 저장소 안 `CLAUDE.md`에 뒀다. 전부 뭔가 깨진 뒤에 추가한 것이다.

## 발췌

2026년 5월 말 기준 파일에서 줄였다. 공개 저장소의 `CLAUDE.md`는 내용은 같고 이모지를 빼서 다시 정리한 판이다.

````markdown
## 🔖 아이콘 / 이모지 컨벤션

### 1. UI 컨트롤 (버튼·툴바·FAB·인라인 액션) → Material Symbols 전용
`<span class="mi mi-sm">아이콘이름</span>` 형식.

### 2. 액션 시트 / 모달 안의 항목 버튼 → Material Symbols 전용
| 의미 | ❌ 이모지 (지양) | ✅ Material Symbol |
|---|---|---|
| 이름 변경 | ✏️ | `edit` |
| 삭제 | 🗑 | `delete` |
| 고정 / 핀 | 📌 | `push_pin` (고정 해제는 `mi-fill` 토글) |

### 3. 본문 안내 / 경고 / toast / alert → 이모지 OK
💡 ⚠️ ❌ ✅ ℹ️ 📎 만 사용.

### 3-1. ❌ 금지 — 파일 타입별 이모지 다양화
메모 본문에 삽입되는 마크다운 링크는 모든 파일에 동일 표지자(📎) 사용.
파일 타입별로 📄📝📊🗜️🎬🎵📃⚙️🌐📜 다양화하면 일관성 깨짐 (해본 적 있음, 2026-05-29 revert).

### 4. 적용 시점
전면 마이그레이션은 별도 작업으로 진행. 새로 추가/수정하는 액션 시트·버튼은 1·2번 규칙을 즉시 따름.

## 📐 기타 코드 컨벤션
- 워크플로: `main` 브랜치 직접 커밋 (feature 브랜치 안 만듦)
- 캐시 버스팅: `js/xxx.js?v=YYYYMMDD?` 형식. 파일 수정 시 버전 bump 필요
- localStorage 키: `mindflow_` 접두사 (utils.js `save()`가 자동 처리)
- 빌드 시스템 없음: 바닐라 JS, deferred script 순서 의존
````

## 메모

- 3-1은 AI가 첨부 링크에 타입별 이모지를 붙였다가 되돌린 뒤 넣었다. 날짜와 "해본 적 있음"을 빼면 다음 세션이 다시 시도한다.
- 4번은 일부러 "새로 만드는 것부터"로 뒀다. 한 번에 다 바꾸라고 하면 그 와중에 다른 게 깨진다.
- "빌드 시스템 없음"이 없으면 AI가 import/export를 쓰고 앱이 안 뜬다.
- 개인 전역 설정에는 결정 전에 반대 의견 먼저 말하기, 수치는 측정값 쓰기, 파일 상태는 확인 후 말하기를 넣었다.

규칙 이후에 만든 버튼은 따랐다. 8월 16일에 추가한 집중 타이머 버튼도 Material Symbols다.
설정 모달의 옛 버튼 12개(백업, 내보내기, Drive 연결 등)에는 아직 이모지가 남아 있다. 4번대로 한꺼번에 바꾸지 않고 둔 부분이다.
